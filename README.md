# 🚀 TrackMyLife

TrackMyLife is an AI-powered journaling application that analyzes daily entries to identify mood and productivity, helping users track their personal growth over time.

## ✨ Features

- 🔐 User Authentication (JWT)
- 📝 Daily Journal Logging
- 🤖 AI-based Mood & Productivity Analysis
- 📊 Mood Analytics Dashboard
- 🔥 Daily Streak Tracker
- 📄 PDF Report Generation
- 📜 Journal History

## 🛠️ Tech Stack

**Frontend:** React.js, Tailwind CSS, Chart.js

**Backend:** Node.js, Express.js

**Database:** PostgreSQL

**Authentication:** JWT, bcrypt

**Deployment:** Vercel, Render

## 🚀 Live Demo

**Live:** https://track-my-life-phi.vercel.app/

## ⚙️ Run Locally

### Backend

```bash
cd backend
npm install
node server.js
```

### Frontend

```bash
cd frontend
npm install
npm start
```
